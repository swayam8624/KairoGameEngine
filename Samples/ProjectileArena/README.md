# Projectile Arena

This is a regular authored game project derived from Combat Arena. Press F to launch a horizontal point projectile along the last movement direction. The optional `projectile SPEED` record in `Config/Combat.kcombat` selects travelling attacks (speed in metres per second); omitting it preserves instantaneous raycast attacks. Damage is applied only on impact. Each fixed tick traces the complete travelled segment against the nearest current solid collider; shots expire at their configured attack range. Existing flights pause with the modal menu and clear on respawn. The pool is capped at 512 simultaneous flights. Launch and impact feedback currently goes to the console; there are no rendered projectile meshes, trails, impact sounds, ballistic arcs, or continuous moving-target collision guarantees.

Run `build/game-clang/Runtime/KairoPlayer/KairoPlayer Samples/ProjectileArena/Project.kproject` after building the game profile. The full-workspace `KairoPlayerProjectileBridgeTests` checks delayed destruction and wall interception using the actual physics adapter. Portable tests cover segment flight, range, capacity, order and combat-state compatibility.
