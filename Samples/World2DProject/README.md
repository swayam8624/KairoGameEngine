# 2D Adventure Starter

Create a 2D Adventure project from the Hub. Author two tile layers, actor positions, colliders, objective triggers, patrols and indexed animation frames up to 32x32 in the 2D workspace. WASD/arrows move; Space jumps in platform mode; R restarts. Import a PNG sprite sheet in the workspace to quantize it to the authored 15 opaque colors plus transparency. Native Player supports Metal and Vulkan overlays. The inline world format is independent of 3D scene assets.
