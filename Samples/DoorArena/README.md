# Door Arena

A regular authored Kairo project with a solid kinematic vertical gate. Approach the gate and it rises; move sufficiently far away and it closes. No new executable is needed. `Config/Doors.kdoor` uses the version header `kairo-doors 1` and rows `door ENTITY_ID LIFT_METRES SPEED_METRES_PER_SECOND ACTIVATION_RADIUS_METRES`. The radius is horizontal and must exceed a conservative player/door bounding radius plus margin. Targets must be opted-in active root leaves with a mesh, non-trigger box collider and kinematic body. The generic Player runs the door controller in the existing fixed-step fanout, updating the scene and authoritative physics body together. The gate is independent of visual proximity actions and objective persistence; its state is derived from player proximity and resets on restart.

Build the normal game profile, then run `build/game-clang/Runtime/KairoPlayer/KairoPlayer Samples/DoorArena/Project.kproject`. The CTest `KairoPlayerDoorBridgeTests` checks real scene/physics/raycast agreement through opening and closing. Portable tests exercise the motion controller independently. The authored vertical travel path must be clear; other moving bodies, swept contacts, crush avoidance and arbitrary joints are not certified by this feature.
