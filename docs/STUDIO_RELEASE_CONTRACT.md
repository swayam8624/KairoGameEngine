# Kairo Studio production release contract

This is the bounded first public engine release scope, not a claim of parity with every feature of a commercial engine. Do not label the release 100% until each gate has actual integrated evidence. Do not require the owner to iterate manually on incomplete native builds; the final owner-run Mac check follows the release candidate gate.

| Gate | Required acceptance | Present evidence / outstanding work |
| --- | --- | --- |
| Project hub | Open/create 2D, 3D and sample projects; recent projects, safe paths, missing-project recovery, engine/version information, no shell command construction from names | Existing project session, recipe compiler and lifecycle tools; dedicated startup hub and template workflow remain |
| Editor interaction | Selection never frames or moves camera; F frames explicitly; Q/W/E/R tools outside RMB; orbit/pan/dolly/free-look on mouse and trackpad; no clicks on toolbar treated as scene picks; undoable local/world transforms, parent hierarchy, cancel and redo | Native shell changes for gesture ownership and explicit framing; local geometry test; full mouse interaction, transformed children, retained selection and Retina picking acceptance pending |
| Selection and visual design | Consistent theme/typography, dock persistence, legible inspector and real asset preview; selected mesh silhouette, nonmesh icons, stable selection while editing | Studio shell and cobalt draw bounds; bounds are not a silhouette, skinned bounds are bind-pose approximations, thumbnails currently type glyphs |
| Scripting | Create source or visual script, edit with meaningful diagnostics and autocomplete/navigation, attach to entity, compile, run, debug, save/reopen; hot reload with defined state policy | Existing logic document compiler, graph/code authoring and native gameplay registration; end-to-end scripting UX and debugger acceptance remain |
| Scene and assets | Create/import/edit objects, lights/cameras/materials/audio, prefabs and scenes; asset import errors and dependency safety; undo/redo; missing-file recovery | Existing project/asset/scene services; representative actual end-to-end projects and graphical workflow validation remain |

| Release and performance | Incremental application build, documented clean build, distributable launchable app, validated package with licenses, no critical crashes/leaks, regression suite and real captures across declared platforms | Target-only build script; native Studio compile/render, Linux Vulkan leak diagnosis, packaging and macOS final run outstanding |

## Evidence rules

Keep actual commands, candidate commit and workspace lock, completed results, logs and captured frames. A portable test cannot certify GPU interaction. A source edit cannot certify native behavior. Missing acceptance is not a percentage. Distinguish static checks, local executed tests, CI and owner device tests. Preserve unmerged work and build caches until verified promotion.

## Pass 1: viewport interaction

Removed implicit camera framing after entity creation/asset placement. Normal selection remains a scene-state operation. RMB captured flight owns movement keys; without RMB, Q/W/E/R select transform tools. Orientation buttons are outside the scene image. Explicit F framing exits the authored camera lens and layer mask; ordinary navigation restores all render layers. Visible mesh selection uses actual submitted draw object IDs, cached mesh-local bounds and each draw model matrix. No per-frame vertex scan or GPU readback. Portable bounds topology test passed 50,000 seeded cases each under GCC, Clang and Clang ASan/UBSan; exact tested blobs in KairoEditor: 1a2fdf95f1ebcd7b38d6e59f3521e0de877aedc7 and 04620d481ec2ed46d83a114fe9c70751112749a5. Native interaction and highlight rendering still require acceptance. A full silhouette, correct skinned deformation bounds, and parent-aware transform gizmos are not claimed.

Next: validate and improve viewport ownership and actual selection on all supported GPU backends; project hub/template workflow; scripting lifecycle and editor integration; then asset, animation, packaging and consolidated acceptance.

## Pass 6: first asset import and folder navigation

Added a native Content Browser import dialog for standalone local OBJ geometry, plus a folder filter composed with search and type filters. Imports require a saved, clean project and an absolute path. The source is copied into a unique project-owned directory (32 MiB cap), registered in a candidate manifest and validated through the actual ImportRenderMesh pipeline; malformed geometry removes the staged directory and leaves the manifest unchanged. Detect externally changed registry state before publication; simultaneous writers and crash-atomic multi-file transactions are not supported. The original source is preserved. The native editor reopens after success to rebuild render bindings; this is not live hot import. No external materials, textures, glTF first import, linked prefab definitions, or file picker are claimed. Registered native regression for malformed source rollback, real geometry, independent IDs, dirty/stale session rejection and reopening. New native compile and regression pending. ## Pass 8: reviewed prefab definition replacement

The Save Prefab modal can explicitly review and replace an existing exact-name definition from the selected hierarchy. The bounded original serialized bytes are the revision token; stale edits, missing definitions, invalid names and unsaved scenes fail closed. The engine's existing staged atomic scene writer publishes the definition. Existing instances are independent and never rewritten. The dialog distinguishes file replacement from scene undo. This does not support simultaneous writers, linked instance synchronization, dependency indexing or prefab file undo. Native regression extended for stale and dirty rejection, independent old/new transforms, reopen and stable placement undo/redo. Native compilation and execution are pending; no owner Mac run requested. Editor pin a05740da4e8f08b7584890d1fd34096a8aefe07f.

## Pass 9: geometric selection contours

Static selected meshes now use camera-dependent contours from cached welded triangle adjacency, respecting submitted draw IDs, parent/model transforms, orthographic and perspective views and mirrored winding. Per-mesh cap 20,000 indexed faces, global cache 200,000 faces and per-frame 8,192 lines; oversized or skinned geometry uses existing bounds. Exact coincident positions are welded within a primitive, not across primitives. CPU geometric contours do not account for scene occluders, alpha cutouts or animated skin deformation and are not a post-process glow. Portable regression registered in CTest; exact source blobs b9ce98729ea25e345ff951a7dd14b5f0f5ed3fca and d821f73db09e7d92748a6265f2d4c8699f7b43a5 passed GCC, Clang and Clang ASan/UBSan with 10,000 seeded transform cases each and seam, mirror, closed-solid, malformed-input and budget fixtures. Native editor compile, visual acceptance and integrated CTest remain pending. Editor pin df265d7868163353f3a93330e1b8f430d834cd31.

## Pass 10: docked animation timeline

The native Timeline panel replaces the floating glTF preview with clip selection, actual position/rotation/scale channel lanes, twelve-track pagination, bounded binary-search key markers, transport, normalized scrubbing, strict adjacent-key navigation and source key value inspection. One active selection/asset owns the preview; changing selection or hiding the panel clears the old override. Playback loops in the clock while the sampler clamps, preserving the final key when paused. No modification of imported sources or authored scene data; persistent keyframe creation/editing and runtime controller authoring remain outstanding. ## Pass 11: persistent authored glTF animation clip

A native draft editor creates one project-authored clip per imported glTF asset, adding rest-TRS tracks or copying bounded imported channels, editing/duplicating/deleting/sorting keys, editing cubic tangents, and selecting step, linear or cubic interpolation. Explicit save validates finite strictly increasing times, unit rotation quaternions, target node identity and bounded counts. The shared Editor/Player glTF import boundary appends the project-owned Animations/<asset-id>.kanim clip after imported clips, retaining imported indices. The sidecar is bound to the derived-data source key, rejects stale disk revisions on save, uses atomic file replacement, and is included by ordinary project packaging traversal. Save updates live animation bindings without restarting the editor. Runtime default remains clip zero; gameplay can select the appended index. Authored clip edits are asset-wide, require rest-TRS nodes, and are not scene undo commands. Simultaneous file writers are not supported; a changed source key is rejected on reload, not automatically retargeted. Multiple authored clips, unsaved draft preview, general scene-entity animation and state-machine editing remain outstanding.

Actual local execution: GCC, Clang, and Clang ASan/UBSan each passed 10,000 codec round trips plus malformed input, stale key, duplicate track, non-unit rotation and truncation rejection fixtures. Local Git blob hashes bb732094cdc54c7882a7394b3cf60274cf04932a and c665b2d5e6c95b30b4c2f6afe3a2c12b68d7b2d9 exactly match GitHub. Native bridge publication/reopen/stale-session/pose regression registered, not executed; native GUI, actual Player package and cross-platform acceptance pending. Editor pin 348c072154960d0df6a62a8ba728ccc6348bfaa4.

## Pass 12: authored animation state machines

Native Timeline editor supports state names, entry state, clip index, speed and loop/clamp, transition endpoints, priority, normalized exit time, blend duration and one optional boolean equality condition. State deletion removes incident transitions and repairs indices. Definitions are asset-wide, source-key-bound, capped at 64 states and 256 transitions; atomic writes reject stale disk content. The shared glTF importer loads the controller alongside authored clips. Player uses independent per-entity EngineCore controller instances and publishes blended asset-bound poses before IK and skin palette extraction. Gameplay explicit clip selection takes precedence; SetControllerBool restores controller ownership and drives declared parameters, default false. ControllerStateName exposes runtime state. The editor can preview the same evaluator with independent test parameters, reset, current state and transition alpha. The state editor is an indexed form, not a graphical node canvas; general numeric/multiple conditions and logic VM parameter binding are not implemented. Controller-enabled glTF assets apply to all their instances by default. Registered native codec round-trip, stale file, invalid reference, per-instance blend and render extraction regression. No execution or native build result claimed for this pass. Full Player and graphical acceptance remain pending. Editor pin 578ea5799a54e87e4a2045db2d5163b86171827d.
